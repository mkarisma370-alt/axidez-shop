Pertanyaan umum

Bagaimana cara membayar?

Setelah pesananmu masuk, admin membalas lewat WhatsApp dengan metode pembayaran yang tersedia. Pilihan metode di halaman pesan hanya preferensimu.

Apakah ID saya disimpan?

Tidak di server. Website ini tidak punya server penyimpanan. ID hanya tersimpan di perangkatmu kalau kamu mengaktifkan "Ingat ID", dan dikirim ke WhatsApp admin saat kamu menekan kirim.

Salah mengisi ID, bagaimana?

Periksa ringkasan sebelum mengirim. Kalau pesan sudah terkirim, segera hubungi admin lewat WhatsApp.

Di mana saya menemukan ID akun?

Setiap game punya petunjuk singkat di bawah kolom ID. Biasanya ada di halaman profil dalam game.
