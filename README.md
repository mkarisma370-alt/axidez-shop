# Axidez Shop v4
Top up game amanah & terpercaya (Mobile Legends, Free Fire, Roblox).

Website statis, cukup `index.html`. GitHub Pages: upload semua file, lalu Settings > Pages > Deploy from branch (main, root).
Harga dan nomor WhatsApp ada di `const D` dalam index.html (markup 0.8 = naik 80%, `add` = tambahan harga tetap).
